Print-format decision

The BS PDF button now calls Purchase Order Print Format, created 3 September 2026, with Order Letterhead. The newer BS format is no longer forced. No changes were made to the September template, logo references, stamp, layout or approval wording. The original logo and stamp files are absent on this test clone, as previously identified; this release does not recreate them.

Operational limits

Use real configured supplier contacts, addresses and tax templates; no tax rates, registrations or project budgets were invented. Project purchasing requires an approved baseline. Services do not require a stock receipt. Foreign-currency settlement, credit notes, landed costs and advance reconciliation are not newly certified. Supplier quotations remain attached comparison evidence rather than separate Supplier Quotation documents.

Versioning and rollback

Branch: feat/bs-procurement-screen-20261019. The code checkpoint contains the procurement implementation and tests; unrelated Lead Intake changes remain outside it. Remote review requires GitHub access. A full deployment rollback requires a matched database/files backup; reverting source alone does not reverse schema, settings, workflows or accounting transactions.
